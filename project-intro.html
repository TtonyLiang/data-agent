核心价值

把智能问数从一次性的模型输出，变成可配置、可检查、可复用的业务能力。

语义层驱动

用指标、映射、关系和规则沉淀统一业务口径。大模型负责理解，编译器负责落地。

多智能体

不同团队可绑定各自的数据源、模型和语义领域，权限彼此隔离。

深度分析

查询结果继续进行趋势、排名、分布和异常分析，输出结构化报告。

从提问到报告

每一步都有明确职责，用户可以查看语义资产、候选表、SQL 和分析结果。

01

理解问题

识别问数意图，结合历史上下文补全问题。

02

定位数据

根据语义资产和授权 Schema 找到候选表字段。

03

生成意图

把问题转换成指标、维度、过滤和排序。

04

受控执行

校验并编译只读 SQL，安全访问业务数据。

05

分析输出

生成统计结论、图表和可读的业务报告。

语义层的六类资产

语义层是项目的核心配置中心，负责把业务语言和真实数据库连接起来。

对象 / 事件 / 状态

定义客户、订单、放款、逾期等业务概念和边界。

关系

定义概念之间的关系和跨表 JOIN 路径。

指标

定义指标公式、基础表、时间字段和可用维度。

规则

处理口径定义、过滤条件、时间规则和归一化。

映射

把语义 key 映射到真实表字段或受控表达式。

LogicForm 模板

为指标查询、趋势分析等常见问法提供结构骨架。

智能，也有边界

项目把理解、执行和分析分开，关键结果可以验证，问题出现时可以定位。

  • 表权限边界每个智能体只在绑定的数据源内工作；配置白名单后，未授权表不会进入候选 Schema。
  • SQL 安全只允许受控的只读查询，执行前拦截危险语句。
  • Python 隔离分析器只处理 SQL 结果集，脚本经过安全检查。
  • 全链路留痕保存问题、SQL、结果、分析过程和报告。
智能体可调用表的权限边界

用户获得智能体访问权
  -> 绑定指定数据源
  -> 表级白名单过滤
  -> 字段隐藏或结果脱敏
  -> 执行前复核 FROM / JOIN
  -> 返回授权范围内的数据

白名单外的表：不参与召回，SQL 执行时再次拦截
